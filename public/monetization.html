Automation

Zero-Touch Revenue Engine

Every step after acquisition should run without manual intervention.

1
Affiliate Link Injection — Automatic
When a product page loads, getAffiliateLinks(product.name, product.brand) generates deep links for all 4 platforms. No manual curation. Tag appended from env var. Vercel Analytics event fires on click.
2
Scan Counter → Paywall Trigger — Automatic
Supabase edge function increments scans_this_month on each /api/analyze call. At scan 8, next product page shows a soft upsell banner. At scan 10, hard paywall modal fires. Resets on 1st of month via Supabase cron.
3
Razorpay Webhook → Feature Unlock — Automatic
Razorpay fires subscription.activated → our webhook at /api/razorpay/webhook → updates profiles.is_premium = true and premium_until in Supabase. User's UI updates in real time via Supabase realtime subscription.
4
Churn Prevention Emails — Automatic
Resend + Supabase cron: 3 days before premium expires → renewal reminder. On cancellation → win-back email with 20% off code. On subscription.halted (payment failure) → dunning sequence (3 emails over 7 days).
5
Monthly Affiliate Report — Automated via Claude
Claude Code scheduled task: pull click data from Vercel Analytics, pull commission estimates from affiliate dashboards, compile a one-page revenue report and email to founder@sift.app every 1st of month.
